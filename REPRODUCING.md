## 📊 Step-by-Step Reproduction

### 1. Environment Setup

**Option A: Conda (Recommended)**
```bash
conda env create -f workflow/environment.yml
conda activate uhdm-agn
```

**Option B: Docker**
```bash
docker build -t uhdm-agn -f workflow/Dockerfile .
docker run -it -v $(pwd):/workspace uhdm-agn
```

**Option C: pip (Manual)**
```bash
pip install -r code/requirements.txt
```

### 2. Data Acquisition (Optional)

Download observational data (or use built-in parameterizations):

```bash
# Fermi-LAT 3FHL Catalog (~50 MB)
wget https://fermi.gsfc.nasa.gov/ssc/data/access/lat/3FHL/gll_psch_v13.fit \
  -O data/fermi_lat_3fhl_catalog.fits

# IceCube and Pierre Auger data
# See data/README_data.txt for details
```

### 3. Run Analysis Modules

#### Generate Individual Figures

```bash
# Figure 1: EFT Validity (Corrected)
python code/eft_cross_sections.py

# Figure 2: Maximum Lorentz Factors
python code/grmhd_acceleration.py

# Figure 3: Production Rates vs Mass
# (Already generated by eft_cross_sections.py)

# Figure 4: Multi-Messenger Constraints
python code/observational_constraints.py

# Figure S1: MCMC Diagnostics (WARNING: 8-12 hours!)
python code/monte_carlo_sampling.py
```

#### Or Generate All Figures at Once

```bash
# Generate all figures
python code/generate_figures.py --output figures/

# Generate specific figures only
python code/generate_figures.py --output figures/ --figures 1,2,4
```

### 4. Run Full Monte Carlo Analysis

**⚠️ WARNING: This step requires ~8-12 hours on a 16-core CPU**

```bash
# Full MCMC analysis (10^6 samples, 5 chains)
python code/monte_carlo_sampling.py

# For testing (faster, less accurate):
# Edit monte_carlo_sampling.py to set n_walkers=16, n_steps=500
```

**Parameters:**
- **Chains:** 5 independent chains
- **Samples:** 10^6 samples per chain
- **Random seeds:** {42, 137, 271, 314, 628}
- **Output:** `data/mc_posterior_samples.h5` (~500 MB)

**Convergence Criteria:**
- Gelman-Rubin R̂ < 1.01
- Effective sample size N_eff > 10^4
- Autocorrelation time τ < 100

### 5. Compile Manuscript

```bash
cd manuscript/

# Using latexmk (recommended)
latexmk -pdf manuscript_final.tex

# Or manually
pdflatex manuscript_final.tex
bibtex manuscript_final
pdflatex manuscript_final.tex
pdflatex manuscript_final.tex
```

**Output:** `manuscript_final.pdf`

## 🔧 Troubleshooting

### Common Issues

**1. LaTeX Compilation Errors**
```bash
# Install missing packages
sudo apt-get install texlive-full  # Ubuntu/Debian
brew install --cask mactex          # macOS
```

**2. MCMC Takes Too Long**
```bash
# Use test parameters
# Edit code/monte_carlo_sampling.py:
#   n_walkers = 16
#   n_steps = 500
```

**3. Memory Errors**
```bash
# Reduce batch size in PDF integration
# Edit code/pdf_integration.py to use smaller arrays
```

**4. Missing LHAPDF**
```bash
# Install LHAPDF (optional, for full CT18 PDFs)
conda install -c conda-forge lhapdf
# Or use simplified PDF model (already in code)
```

**5. Figure Generation Fails**
```bash
# Check matplotlib backend
python -c "import matplotlib; print(matplotlib.get_backend())"

# Set non-interactive backend
export MPLBACKEND=Agg
```

## 🎨 Customization

### Modify MCMC Parameters

Edit `code/monte_carlo_sampling.py`:

```python
# Number of walkers and steps
n_walkers = 32  # Default: 32
n_steps = 10000  # Default: 10000

# Random seeds
seeds = [42, 137, 271, 314, 628]

# Priors
log10(M/M_⊙) ~ U(8, 10)   # Black hole mass
log10(B/G) ~ U(2, 4)       # Magnetic field
C_i ~ logU(10^-3, 1)       # EFT coupling
```

### Modify Figure Styling

Edit individual plotting scripts:

```python
# In code/eft_cross_sections.py
plt.figure(figsize=(10, 7))  # Change figure size
plt.rcParams['font.size'] = 14  # Change font size
```
